# Electrochemical Test Data & Loaders: MACCOR & Gamry

This repository provides standardized, anonymized sample test files, loader utilities, and test suites for electrochemical data generated by **MACCOR Automated Test Systems** and **Gamry Instruments Potentiostats**.

It contains sample data files representing common testing protocols (Electrochemical Impedance Spectroscopy / EIS, Cyclic Voltammetry / CV, and Galvanostatic Cycling) along with unit tests and analysis utilities verifying parser compatibility and equivalent circuit fitting.

---

## Included Sample Data Files

| File | Instrument | Technique | Description |
| :--- | :--- | :--- | :--- |
| `data/gamry_impedance_sample.DTA` | Gamry Potentiostat | Full EIS Impedance Test (`EISPOT`) | Complete 86-point spectrum (300 kHz to 0.001 Hz), $Z_{real}$, $Z_{imag}$, OCV curve, and metadata. |
| `data/gamry_eis_sample.DTA` | Gamry Potentiostat | High-Frequency EIS (`EISPOT`) | Gamry `.DTA` containing test metadata, OCV curve, and high-frequency `ZCURVE`. |
| `data/gamry_cv_sample.DTA` | Gamry Potentiostat | Cyclic Voltammetry (`PWR800_CV`) | Raw Gamry `.DTA` with scan parameters, OCV curve, and `CURVE1` tabular scan data. |
| `data/gamry_cv_sample.csv` | Gamry Potentiostat | Cyclic Voltammetry Export | Tab-delimited exported file featuring standard Gamry header rows (`#`, `s`, `V vs. Ref.`, `A`). |
| `data/maccor_cycling_sample.csv` | MACCOR Cycler | Galvanostatic Cycling | Comma-delimited export with records, cycles, steps, time, current (`Amps`), and voltage (`Volts`). |
| `data/maccor_cycling_sample.xlsx` | MACCOR Cycler | Galvanostatic Cycling | Excel workbook export with multi-cycle charge/discharge test series. |

## Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone git@github.com:km-kushmathur/supercapacitor-testing.git
   cd supercapacitor-testing
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

---

## Running the Test Suite

Run all unit tests (including impedance tests, CV loaders, and MACCOR loaders):

```bash
python3 -m unittest discover tests
```

Or run the impedance tests specifically:

```bash
python3 -m unittest tests/test_impedance.py
```

---

## Running Impedance Analysis & Plotting

To analyze `data/gamry_impedance_sample.DTA`, fit the series RC equivalent circuit, and output a squared Nyquist plot:

```bash
python3 analyze_impedance.py
```

This generates `nyquist_plot.png` with equal aspect ratio geometry (1 $\Omega$ on $X$ equals 1 $\Omega$ on $Y$).

## Quickstart: Using the Loaders

### Loading Gamry Impedance Data (`.DTA`)

```python
from tests.test_gamry_loaders import load_gamry_dta
from tests.test_impedance import fit_series_rc

header, tables = load_gamry_dta("data/gamry_impedance_sample.DTA")
zcurve = tables["ZCURVE"]

# Fit equivalent circuit parameters
fit = fit_series_rc(zcurve["Freq"], zcurve["Zreal"], zcurve["Zimag"])
print(f"Rs: {fit['Rs_ohm']:.2f} ohm, C: {fit['Capacitance_F']:.2f} F")
```

### Loading Gamry CV Data (`.csv`)

```python
from tests.test_gamry_loaders import load_gamry_cv_csv

df_cv = load_gamry_cv_csv("data/gamry_cv_sample.csv")
print(df_cv[["s", "V vs. Ref.", "A"]].head())
```

### Loading MACCOR Cycling Data (`.xlsx` or `.csv`)

```python
from tests.test_maccor_loaders import load_maccor_excel, load_maccor_csv

# Load Excel cycling data
df_excel = load_maccor_excel("data/maccor_cycling_sample.xlsx")
cycle_1 = df_excel[df_excel["Cyc#"] == 1]
print(f"Cycle 1 records: {len(cycle_1)}")

# Load CSV cycling data
df_csv = load_maccor_csv("data/maccor_cycling_sample.csv")
print(df_csv[["Cyc#", "Step", "Test (Min)", "Amps", "Volts"]].head())
```
