# Electrochemical Test Data & Loaders: MACCOR & Gamry

This repository provides standardized, anonymized sample test files and verified loader utilities for electrochemical data generated by **MACCOR Automated Test Systems** and **Gamry Instruments Potentiostats**.

It contains sample data files representing common testing protocols (Electrochemical Impedance Spectroscopy, Cyclic Voltammetry, and Galvanostatic Cycling) along with a test suite verifying parser compatibility.

---

```text
    └── test_maccor_loaders.py    # Loaders and unit tests for MACCOR formats
```

## Included Sample Data Files

| File | Instrument | Technique | Description |
| :--- | :--- | :--- | :--- |
| `data/gamry_eis_sample.DTA` | Gamry Potentiostat | Potentiostatic EIS (`EISPOT`) | Raw Gamry `.DTA` containing test metadata, OCV curve, and `ZCURVE` (frequency, $Z_{real}$, $Z_{imag}$). |
| `data/gamry_cv_sample.DTA` | Gamry Potentiostat | Cyclic Voltammetry (`PWR800_CV`) | Raw Gamry `.DTA` with scan parameters, OCV curve, and `CURVE1` tabular scan data. |
| `data/gamry_cv_sample.csv` | Gamry Potentiostat | Cyclic Voltammetry Export | Tab-delimited exported file featuring standard Gamry header rows (`#`, `s`, `V vs. Ref.`, `A`). |
| `data/maccor_cycling_sample.csv` | MACCOR Cycler | Galvanostatic Cycling | Comma-delimited export with records, cycles, steps, time, current (`Amps`), and voltage (`Volts`). |
| `data/maccor_cycling_sample.xlsx` | MACCOR Cycler | Galvanostatic Cycling | Excel workbook export with multi-cycle charge/discharge test series. |

## Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone <repository-url>
   cd <repository-directory>
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

## Running the Test Suite

Run all unit tests using Python's built-in `unittest` runner:

```bash
python -m unittest discover tests
```

Or using `pytest`:

```bash
pytest tests
```

## Quickstart: Using the Loaders

### Loading Gamry EIS Data (`.DTA`)

```python
from tests.test_gamry_loaders import load_gamry_dta

header, tables = load_gamry_dta("data/gamry_eis_sample.DTA")

# Access metadata
print("Protocol:", header.get("TAG"))

# Access EIS impedance curve
zcurve = tables["ZCURVE"]
print(zcurve[["Freq", "Zreal", "Zimag"]].head())
```

### Loading Gamry CV Data (`.csv`)

```python
from tests.test_gamry_loaders import load_gamry_cv_csv

df_cv = load_gamry_cv_csv("data/gamry_cv_sample.csv")
print(df_cv[["s", "V vs. Ref.", "A"]].head())
```

### Loading MACCOR Cycling Data (`.xlsx` or `.csv`)

```python
from tests.test_maccor_loaders import load_maccor_excel, load_maccor_csv

# Load Excel cycling data
df_excel = load_maccor_excel("data/maccor_cycling_sample.xlsx")
cycle_1 = df_excel[df_excel["Cyc#"] == 1]
print(f"Cycle 1 records: {len(cycle_1)}")

# Load CSV cycling data
df_csv = load_maccor_csv("data/maccor_cycling_sample.csv")
print(df_csv[["Cyc#", "Step", "Test (Min)", "Amps", "Volts"]].head())
```
